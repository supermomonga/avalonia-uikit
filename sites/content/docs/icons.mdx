The components draw [Lucide](https://lucide.dev) icons. The theme bundles them, and every other icon GPUI Kit ships for its components, as `StreamGeometry` resources, so the icons an app places next to the components match them exactly, and no SVG parser is needed at run time (the geometry is compiled XAML, which suits NativeAOT). Lucide is licensed under the ISC License; the license ships with the package in `THIRD-PARTY-NOTICES.md`.

## Usage

Set a `PathIcon`'s `Data` to the icon's resource. The icon is 16px, the medium size, and takes the `Foreground`:

```xml
<PathIcon Data="{StaticResource UIKit.Icon.Search}" />
<PathIcon Data="{StaticResource UIKit.Icon.TriangleAlert}"
          Foreground="{DynamicResource UIKit.Warning}" />
```

The classes `xsmall`, `small` and `large` give the other sizes, 12, 14 and 24px:

```xml
<PathIcon Classes="small" Data="{StaticResource UIKit.Icon.ChevronDown}" />
<PathIcon Classes="large" Data="{StaticResource UIKit.Icon.Bell}" />
```

Any other geometry works the same way; the theme's `PathIcon` scales whatever `Data` it gets to its size.

`uikit:Icon` is a `PathIcon` that takes the icon by name instead: `Kind` is an `IconName`, GPUI Kit's names for its icons. The sizes and colors are the same:

```xml
<uikit:Icon Kind="Search" />
<uikit:Icon Classes="large" Kind="TriangleAlert"
            Foreground="{DynamicResource UIKit.Warning}" />
```

In code, `IconName.Search.ResourceKey()` is the resource's key, `UIKit.Icon.Search`.

The `IconName` column is the `Kind` that draws the icon with `uikit:Icon`.
