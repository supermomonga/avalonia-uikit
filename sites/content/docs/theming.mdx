## Light and dark

The theme comes in light and dark. Switch with Avalonia's `RequestedThemeVariant`, on the application or on any control:

```xml
<Application RequestedThemeVariant="Dark">
```

```xml
<Border RequestedThemeVariant="Light">
  <Button Content="Always light" />
</Border>
```

## Color tokens

Every color of the theme is a resource with a `UIKit.` prefix: the base tokens (`UIKit.Background`, `UIKit.Foreground`, `UIKit.Border`, `UIKit.Primary`, `UIKit.PrimaryForeground`, `UIKit.Secondary`, `UIKit.Muted`, `UIKit.MutedForeground`, `UIKit.Accent`, `UIKit.Danger`, `UIKit.Warning`, `UIKit.Success`, `UIKit.Info`, `UIKit.Link`, `UIKit.Popover`, `UIKit.FocusRing`, the palette colors `UIKit.Blue`, `UIKit.Green` and so on) and the colors the components derive from them for their states (`UIKit.Button.Primary.Hover.Background`, for example). Each token is a `SolidColorBrush`; the `Color` is the same key with a `.Color` suffix. Use them with `DynamicResource` so they follow the theme variant:

```xml
<Border Background="{DynamicResource UIKit.Muted}"
        BorderBrush="{DynamicResource UIKit.Border}">
  <TextBlock Foreground="{DynamicResource UIKit.MutedForeground}" Text="Muted" />
</Border>
```

The tokens are generated, so they are not meant to be edited by hand. An application can still override one in `Application.Resources`, which Avalonia checks before the theme; the derived colors are resources of their own and do not follow the override.

## Font

The theme uses the platform's UI font: `UIKit.FontFamily` is `$Default`. The demos on this site use Inter; to match them, add Inter to your app and override the resource:

```xml title="App.axaml"
<Application.Resources>
  <FontFamily x:Key="UIKit.FontFamily">avares://MyApp/Assets/Fonts#Inter</FontFamily>
</Application.Resources>
```

The other metrics are resources too: `UIKit.FontSize` (16) with `UIKit.FontSize.Xs`, `.Sm`, `.Base` and `.Lg` (12, 14, 16, 18), `UIKit.Radius` (6) and `UIKit.RadiusLg` (8), and the springs `UIKit.Spring.Control` and `UIKit.Spring.Move` that drive the motion.

## Sizes

The components come in four sizes. Pick one with a style class; the default is medium.

```xml
<Button Classes="xsmall" Content="XSmall" />
<Button Classes="small" Content="Small" />
<Button Content="Medium" />
<Button Classes="large" Content="Large" />
```

`Button`, `SplitButton`, `ToggleButton`, `CheckBox`, `RadioButton`, `ToggleSwitch`, `TextBox`, `NumericUpDown`, `ComboBox`, `AutoCompleteBox`, `ProgressBar`, `PathIcon`, `TabStrip` and the new controls take `xsmall`, `small` and `large`.

## Variants

Variants are style classes as well, and the classes combine freely:

```xml
<Button Classes="primary" Content="Primary" />
<Button Classes="danger outline small" Content="Delete" />
<Button Classes="ghost icon-only">
  <PathIcon Data="{StaticResource UIKit.Icon.Copy}" />
</Button>
```

| Control | Classes |
| --- | --- |
| `Button` | Colors: `primary`, `secondary`, `danger`, `warning`, `success`, `info`, `ghost`, `link`, `text` (none is Default). Modifiers: `outline`, `compact`, `selected`, `icon-only`. Radius: `rounded-none`, `rounded-small`, `rounded-large`, `rounded-full`. |
| `SplitButton` | The Button's colors, `outline`, `selected` and sizes. |
| `ToggleButton`, `ListBox.toggle-group` | `outline` (ghost is the default); the toggle group also `segmented`. |
| `ToggleSwitch` | `label-left`. |
| `GroupBox` | `fill`, `outline` (normal is the default). |
| `Separator` | `vertical`, `dashed`. |
| `TabStrip`, `TabControl` | `pill`, `segmented`, `underline`. |
| `TextBox` | `revealPasswordButton`; `group` for an input group. |
| `ComboBox` | `combobox` for the Combobox look. |
| `Image` | `rounded`, `rounded-lg`, `rounded-full`. |
| `uikit:Alert` | `info`, `success`, `warning`, `error`. |
| `uikit:TagLabel` | `primary`, `secondary`, `danger`, `success`, `warning`, `info` or a palette color (`red`, `blue`, `emerald`…); `outline`, `transparent`, `fill`. |
| `uikit:Kbd` | `outline`. |
| `uikit:Skeleton` | `secondary`. |

A class the theme does not know is ignored, so a typo gives the default look rather than an error.

## Named themes

A few components are another look of an Avalonia control, chosen with `Theme`:

```xml
<ProgressBar Theme="{StaticResource UIKitSpinner}" IsIndeterminate="True" />
<ProgressBar Theme="{StaticResource UIKitProgressCircle}" Value="60" />
<Expander Theme="{StaticResource UIKitCollapsible}" Header="Details" />
<TableView Theme="{StaticResource UIKitTable}" />
```
