## Package

<Callout title="Not on NuGet yet" variant="warning">
The packages are not published to NuGet.org yet. Until they are, reference the projects from a clone of the [repository](https://github.com/supermomonga/avalonia-uikit) (`src/AvaloniaUIKit/AvaloniaUIKit.csproj` and, if needed, the two optional projects), for example as a git submodule with a `ProjectReference`. The commands below show the intended way once the packages are out.
</Callout>

```bash
dotnet add package AvaloniaUIKit
```

The themes for Avalonia's optional packages are separate, so an app that does not use them takes no extra dependency:

```bash
dotnet add package AvaloniaUIKit.ColorPicker
dotnet add package AvaloniaUIKit.DataGrid
```

The library targets the current Avalonia 12 release and the latest .NET SDK.

## Theme

Add `UIKitTheme` to the application's styles. It is a `Styles` theme, like `FluentTheme`, and works on its own: it also themes the window, popups, the adorner layer and the focus ring. It follows the application's theme variant: Default Light and Default Dark, or one of the bundled color themes (see [Theming](/docs/theming)).

```xml title="App.axaml"
<Application xmlns="https://github.com/avaloniaui"
             xmlns:x="http://schemas.microsoft.com/winfx/2006/xaml"
             xmlns:uikit="clr-namespace:AvaloniaUIKit;assembly=AvaloniaUIKit"
             x:Class="MyApp.App">
  <Application.Styles>
    <uikit:UIKitTheme />
  </Application.Styles>
</Application>
```

The optional packages add a theme each, after `UIKitTheme`:

```xml title="App.axaml"
<Application xmlns="https://github.com/avaloniaui"
             xmlns:x="http://schemas.microsoft.com/winfx/2006/xaml"
             xmlns:uikit="clr-namespace:AvaloniaUIKit;assembly=AvaloniaUIKit"
             xmlns:uikitcolor="clr-namespace:AvaloniaUIKit;assembly=AvaloniaUIKit.ColorPicker"
             xmlns:uikitgrid="clr-namespace:AvaloniaUIKit;assembly=AvaloniaUIKit.DataGrid"
             x:Class="MyApp.App">
  <Application.Styles>
    <uikit:UIKitTheme />
    <uikitcolor:UIKitColorPickerTheme />
    <uikitgrid:UIKitDataGridTheme />
  </Application.Styles>
</Application>
```

In XAML that uses the new controls, map the namespace with `using:`:

```xml
xmlns:uikit="using:AvaloniaUIKit"
```

### On top of FluentTheme

`UIKitTheme` only themes the controls listed under [Components](/components). To keep a look for the others, add `FluentTheme` first; the later theme wins, and the themed controls look the same with or without Fluent underneath.

```xml title="App.axaml"
<Application.Styles>
  <FluentTheme />
  <uikit:UIKitTheme />
</Application.Styles>
```

## NativeAOT

`AvaloniaUIKit` and `AvaloniaUIKit.ColorPicker` are trimmable and AOT compatible: compiled bindings by default, and reflection is banned by an analyzer. Avalonia's `DataGrid` itself is not trimmable, so `AvaloniaUIKit.DataGrid` gives no NativeAOT guarantee; the basic table is `TableView`, in the main package.
