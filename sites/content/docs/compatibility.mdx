The table lists each component the library covers, the Avalonia control (or the new `uikit:` control) that carries its look, and the optional package when the theme is not in `AvaloniaUIKit` itself. A control written as `TextBox.group` is the control with that style class; one written as `ProgressBar (UIKitSpinner)` is the control with that named theme.

The status means:

- **Full**: the control's look and motion are covered.
- **Partial**: the documented part of the control is themed. The features beyond it are listed on the component's page under "Not covered", and the theme does not try to rebuild them.
- **New control**: a small control the library adds because Avalonia has no counterpart.
