## Usage

The theme covers `TreeView` and `TreeViewItem`: 16px text with 4px of vertical padding, 16px of indent per level, and a folder (open when expanded) or file icon before the label, with the hover and selection colors of a list.

## Not covered

- GPUI Kit's data model and virtualization; bind `ItemsSource` as usual.
