## Usage

The theme covers `ListBox` and `ListBoxItem`: 34px rows of 16px text with 12×4 padding, square and full width, with no chrome of the list's own. A hovered row takes the list hover color (`UIKit.ListHover`), the selected row the active color (`UIKit.ListActive`; hovering adds nothing), and a disabled item shows muted text; the scrollbar overlays the rows, from the `ScrollViewer` theme. Put a row's content in the `ItemTemplate`. The items panel stays virtualizing, so a long list is the same control: see [Virtual List](/docs/components/virtual-list).
