## Usage

`ListBox` virtualizes with a `VirtualizingStackPanel` by default, and the theme keeps that panel, so the rows and the overlay scrollbar of the [List](/docs/components/list) apply to long lists as they are. Bind `ItemsSource` and give the row a `DataTemplate` in `ItemTemplate`; the demo lists ten thousand records, and only the rows in view are realized. GPUI Kit's VirtualList looks the same as its List, so there is no class to add.

## Not covered

- Two-dimensional virtualization.
