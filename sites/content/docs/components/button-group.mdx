## Usage

Put the buttons in a `StackPanel Classes="button-group"` (horizontal or vertical). The theme removes the spacing and the inner corners, and keeps one border between neighbours. Each button is still a `Button`, with its own classes.

## Not covered

- A group-level API; the group is only the panel and its buttons.
