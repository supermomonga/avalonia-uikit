## Usage

The theme covers `ComboBox` and `ComboBoxItem`: the trigger as the input frame with the muted chevron, and the dropdown as GPUI Kit's popover with rounded rows and the check mark on the selected one. Sizes: `xsmall`, `small`, `large`.

## Not covered

- A search field inside the popup (see Combobox).
- Grouped items.
- A clear button.
