## Usage

The theme covers `CalendarDatePicker`: the field as GPUI Kit's input frame with the calendar icon, and the dropdown as the themed `Calendar`, opening with GPUI's fade and slide. Sizes: `xsmall`, `small`, `large`.

## Not covered

- Date ranges.
- Presets such as "Last 7 days".
- Editing the time in the same picker (use `TimePicker` alongside).
