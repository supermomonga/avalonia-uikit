## Usage

Add the `AvaloniaUIKit.ColorPicker` package and `GpuiColorPickerTheme` after `GpuiTheme`. The theme covers `ColorPicker` and `ColorView`: the trigger as GPUI Kit's input frame with the swatch, the popover surface, and Avalonia's palette, spectrum and component sliders in the theme's colors.

## Not covered

- GPUI Kit's own palette, featured row and HSL sliders; Avalonia's `FluentColorPalette` and RGB / HSV components are used instead.
