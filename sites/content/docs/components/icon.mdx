## Usage

Set a `PathIcon`'s `Data` to a bundled icon such as `{StaticResource Gpui.Icon.Search}`; the icon is 16px and takes the `Foreground`. Sizes: `xsmall` (12px), `small` (14px), `large` (24px). See [Icons](/docs/icons) for the list.

## Not covered

- Loading arbitrary SVG files at run time.
- An `IconName`-compatible API; icons are resources.
