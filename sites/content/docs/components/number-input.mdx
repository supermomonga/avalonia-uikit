## Usage

The theme covers `NumericUpDown` (and `ButtonSpinner`) in full: the input frame with the minus button before the value and the plus button after it, as GPUI Kit lays it out. Sizes: `xsmall`, `small`, `large`.

## Not covered

- `ButtonSpinnerLocation`; the buttons stay at GPUI Kit's [−] value [+] positions.
