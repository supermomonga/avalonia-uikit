## Usage

`TextBlock Classes="label"` (and `SelectableTextBlock`) puts the text in the foreground color on GPUI Kit's fixed 20px line, whatever the font size, and wraps it when the width is constrained; a `Run Classes="secondary"` inside it is muted. Sizes and weights are the app's `FontSize` and `FontWeight`, as GPUI's `text_*` and `font_*` are. Avalonia's `Label` control gets the same look and keeps its `Target`. `TextBlock` has no default theme of its own, as one would retarget the text in every template.
