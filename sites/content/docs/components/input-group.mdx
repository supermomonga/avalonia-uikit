## Usage

`TextBox Classes="group"` draws the frame around `InnerLeftContent` and `InnerRightContent`, so a label, an icon or a button sits inside the input. The focus color interpolates as GPUI Kit's does.

## Not covered

- `BlockStart` / `BlockEnd` addons above and below the field.
