## Usage

The theme covers `TextBox` (and `MaskedTextBox`): the frame with the input border that turns to the ring on focus, the muted placeholder, the clear button, and `revealPasswordButton` for GPUI's mask toggle. Sizes: `xsmall`, `small`, `large`.

## Not covered

- GPUI Kit's validation and mask syntax (use `MaskedTextBox` or your own validation).
- Clearing with Esc.
- Inline tokens.
