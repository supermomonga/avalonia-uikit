## Usage

`gpui:ShimmerText` shows its `Text` with a highlight sweeping across it. As in GPUI Kit, the glyphs are painted again twelve times, each clipped to a narrower band around the sweep's center, in a color mixed from the text color toward the theme's background (the foreground on a dark theme). The text's size and color are the app's: set `FontSize` and `Foreground` as on a `TextBlock`. Each instance runs its own clock.

| Property | Meaning |
| --- | --- |
| `Text` | The text. |
| `Duration` | One sweep; 2 seconds by default. |
| `Repeats` | Whether the sweep repeats (the default) or runs once. |
| `IsReversed` | Sweeps from the end to the start. |
| `Spread` | Half the band's width as a share of the text's width; 0.3 by default. |
| `HighlightColor` | The highlight's color; computed from the text color when unset. |
