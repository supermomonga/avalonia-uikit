## Usage

`gpui:Avatar` draws a circle on the secondary color with a 1px ring: the image (cover) if there is one, else the initials on a hue picked from the name, else the placeholder icon. `gpui:AvatarGroup` overlaps its avatars. Sizes: `xsmall` (16px), `small` (24px), the default medium, `large`.

## Not covered

- Fetching the image from a URL (give the avatar a loaded bitmap).
