## Usage

`uikit:Rating` is a row of `Maximum` stars (5 by default) with `Value` of them filled, in the theme's yellow or `ActiveBrush`. The pointer previews the value under it; a click sets `Value` to that star, or to the star before when that star is already filled, so a rating can be cleared down to zero. `Value` binds two-way by default. A disabled rating shows its value only. Each star is a `uikit:RatingStar` with the `:filled` and `:active` pseudo-classes.

| Class | Star icon |
| --- | --- |
| `xsmall` | 12px |
| `small` | 14px |
| (medium) | 16px |
| `large` | 24px |
