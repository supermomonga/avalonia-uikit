## Usage

`ProgressBar Theme="{StaticResource GpuiSpinner}"` draws GPUI Kit's loader icon turning once every 0.8 seconds, with an ease-in-out on each turn. The theme sets `IsIndeterminate` itself, and the icon takes `Foreground`, the text color by default. Sizes: `xsmall` (12px), `small` (14px), `large` (24px); medium (16px) needs no class.
