## Usage

`gpui:Message` places a `gpui:Bubble` with a header above and a footer below, aligned to the start or the end. Stack messages in a `StackPanel` with `Spacing="8"` for GPUI Kit's message group.

## Not covered

- MessageGroup as a control (a `StackPanel` with `Spacing="8"` is the same).
- Setting the header's and footer's insets separately.
