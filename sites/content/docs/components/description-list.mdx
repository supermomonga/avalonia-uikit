## Usage

`gpui:DescriptionList` lays out `gpui:DescriptionItem` children (a `Label` and a `Value`, or content) in `Columns`; an item can `Span` several columns, and `gpui:DescriptionSeparator` breaks the grid. The list can be bordered, and vertical or horizontal.
