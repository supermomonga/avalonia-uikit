## Usage

The theme covers `HyperlinkButton` in full: the text in the link color with a 1px underline at half strength; hovered, the text fades to 80% and the underline turns solid; pressed, the text fades to 60%. The text's line height is phi (1.618) of its size. `NavigateUri` opens the link; `Click` or `Command` run anything else.
