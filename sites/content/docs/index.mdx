Avalonia UIKit is a set of themes and controls for [Avalonia](https://avaloniaui.net), based on the Nova style of [shadcn/ui](https://ui.shadcn.com) and on [GPUI Kit](https://github.com/longbridge/gpui-kit). It is two things:

- **`NovaTheme`**, a `Styles` theme for Avalonia's own controls: `Button`, `TextBox`, `ComboBox`, `TabControl`, `Calendar`, `ListBox`, `TreeView`, `TableView`, `Menu`, `ToolTip` and the rest. The theme replaces each control's `ControlTheme`, so it changes the colors, the padding, the outlines, the inner layout, the states and the animations, not just the palette.
- **A few new controls** in the `uikit:` namespace for the small components Avalonia has no counterpart for: `Badge`, `TagLabel`, `Alert`, `Avatar`, `Breadcrumb`, `Kbd`, `Clipboard`, `Rating`, `EmptyState`, `Skeleton`, `StatusBar`, `DescriptionList`, `Stepper`, `Form`, `HoverCard`, `ShimmerText`, `Marker`, `Bubble` and `Message`.

Every component is checked against reference renders: Light and Dark, each variant, size and state, and the motion frame by frame. The color tokens are generated, including the colors the components derive for their states, so no color is approximated by hand.

The library is built for NativeAOT. It uses compiled bindings only and bans reflection at build time, and a NativeAOT smoke test renders every control in both themes on each change.

## What it is not

The library themes looks, not systems. Components that need a mechanism of their own, such as a modal layer, search, docking, text editing or charts, are out of scope.
