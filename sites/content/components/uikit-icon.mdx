## Usage

`uikit:Icon` draws an icon by name: `Kind` is one of the `IconName` values, the icons GPUI Kit ships for its components (listed in [Icons](/docs/icons)). It is a `PathIcon`, so the size classes of the [Icon](/components/icon), `Foreground`, and the sizes buttons and menus give their icons apply to it the same way. `IconNames.ResourceKey` gives an icon's geometry resource for code.
