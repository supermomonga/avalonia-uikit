## Usage

Put a `GridSplitter` in a 1px column or row of a `Grid` and set `ResizeDirection` to `Columns` or `Rows`: the theme keys the handle's orientation on it. The handle is a 1px hairline in the border color inside a 9px band that takes the pointer and overlaps both panels. A muted pill grows along it and fades in with the state over 120ms: hovered 20px at 35%, pressed 28px at 60%, dragging 44px at 90%; keyboard focus shows the hovered pill. The panels resize with the grid's definitions, so put the limits there (`MinWidth`, `MinHeight`). To leave out the 1px column, put the splitter at the start of the second panel's cell with `ResizeBehavior="PreviousAndCurrent"` and give each panel `MinWidth="100"`.
