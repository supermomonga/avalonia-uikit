## Usage

`uikit:TagLabel` (named so because every Avalonia control already has a `Tag` property) shows its `Content` on a small bordered label. The color is a class: `primary` (the default), `secondary`, `danger`, `success`, `warning`, `info`, or a palette color: `neutral`, `gray`, `red`, `orange`, `amber`, `yellow`, `lime`, `green`, `emerald`, `teal`, `cyan`, `sky`, `blue`, `indigo`, `violet`, `purple`, `fuchsia`, `pink`, `rose`. `outline` keeps the border and gives the text the color. The classes combine, as in `Classes="rose outline small"`. A hovered tag fades to 90%.

| Class | Text and padding |
| --- | --- |
| `xsmall`, `small` | 10px, 6×2, radius 3 |
| default | 12px, 10×4 |
| `large` | 14px, 10×4 |
| `rounded-full` | A pill at any size |
