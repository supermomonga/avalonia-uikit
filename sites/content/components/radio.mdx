## Usage

The theme covers `RadioButton`: the circle with the label after it, the dot fading in on `UIKit.Spring.Control`. Buttons with the same `GroupName` select one of them; there is no separate RadioGroup type. Sizes: `xsmall`, `small`, `large` (medium is the default). As with the checkbox, a `RadioButton` without `Content` drops the label, and the focus ring shows on keyboard focus only.
