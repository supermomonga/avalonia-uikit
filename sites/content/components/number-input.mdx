## Usage

The theme covers `NumericUpDown` (and `ButtonSpinner`): the input frame with the decrease button before the value, the text centred between the buttons, and the increase button after it. The buttons stay at the sides by contract: `ButtonSpinnerLocation` has no effect. `Value`, `Minimum`, `Maximum`, `Increment` and `FormatString` are Avalonia's own. `InnerLeftContent` and `InnerRightContent` are a prefix and a suffix, right beside the value. A right click on the value opens the [Input](/components/input)'s menu (Cut, Copy, Paste, Select All). The frame shows the ring while anything in it has focus; a disabled field fades as a whole to 50%. Sizes: `xsmall` (20px), `small` (24px), medium (32px, the default) and `large` (44px).

[`uikit:NumberInput`](/components/uikit-number-input) keeps the text a number while it is typed, and adds its own stepping rules.
